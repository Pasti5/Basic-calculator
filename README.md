To build this program on Linux:
1. Download and extract the downloaded folder.
2. Make sure you have "cmake" (version 3.24 or newer) and "make" installed.
3. Go to the directory with downloaded sources (where CMakeLists.txt is) and enter the "build" directory.
4. Open terminal there and type "cmake -S ..", and next type "make". Now in the current folder you should be able to find the executable file.

To build this program on Windows:
1. Download and extract the downloaded folder.
2. Make sure you have "cmake" (version 3.24 or newer) installed.
3. Go to the directory with downloaded sources (where CMakeLists.txt is) and enter the "build" directory.
4. Open terminal there and type "cmake -S ..", and next type "ninja". Now in the current folder you should be able to find the executable file.
