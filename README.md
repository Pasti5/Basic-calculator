To build this program on Linux:
1. Download and extract the downloded folder.
2. Make sure you have "cmake" (version 3.24 or newer) and "make" installed.
3. Go to the directory with downloaded sources (where CMakeLists.txt is)
4. Open terminal there and type "cmake -B build", next "cd build" and finally "make". In the current "build" folder you should be able to find the executable file.

To build this program on Windows:
1. Download and extract the downloded folder.
2. Make sure you have "cmake" (version 3.24 or newer) installed.
3. Go to the directory with downloaded sources (where CMakeLists.txt is)
4. Open shell terminal there and type "cmake -B build", next "cd build" and finally "ninja". In the current "build" folder you should be able to find the executable file.
