To build this program on Linux\+:
\begin{DoxyEnumerate}
\item Download and extract the downloaded folder.
\item Make sure you have "{}cmake"{} (version 3.\+23 or newer) and "{}make"{} installed.
\item Go to the directory with downloaded sources (where CMake\+Lists.\+txt is), next create and enter the "{}build"{} directory.
\item Open terminal there and type "{}cmake -\/\+S .."{}, and next type "{}make"{}. Now in the current folder you should be able to find the executable file.
\end{DoxyEnumerate}
